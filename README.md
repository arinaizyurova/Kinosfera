# Киносфера — бронирование мест в кинозале

Итоговая работа по дисциплине «Web-программирование». Вариант 15.

Автор: Изюрова Арина Сергеевна, группа 3-ТИД-3.

## Запуск

Откройте index.html в браузере или запустите статический HTTP-сервер в папке сайта.
Для предсказуемого хранения между вкладками рекомендуется HTTP-сервер или GitHub Pages.

## Возможности

- Три независимых сеанса, схема 10 рядов по 15 мест.
- Выбор и отмена выбора мест, автоматический расчёт суммы.
- Занятые места недоступны для бронирования.
- Проверка имени и телефона регулярными выражениями при вводе.
- Сохранение сеансов в localStorage, выбора и текущего сеанса в sessionStorage.
- Подтверждение бронирования и обновление данных между вкладками.
- Адаптивная вёрстка; на узком экране схема зала прокручивается горизонтально.

## Файлы

- index.html — структура страницы.
- style.css — оформление и адаптивная сетка.
- script.js — генерация мест, валидация, расчёт стоимости и хранение.

Это учебный фронтенд-проект. Фильм вымышленный, оплаты нет. Данные мест хранятся
в браузере, общего сервера и синхронизации между устройствами нет.
Форма не отправляет телефон или имя на сервер и не сохраняет их в localStorage.
